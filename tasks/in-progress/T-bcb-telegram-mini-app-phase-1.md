# T-bcb-telegram-mini-app-phase-1

## Goal

Create the first Telegram Mini App frontend skeleton for Business Context Builder.

## Scope

- Add a static, framework-free Mini App UI skeleton.
- Include start, interview, result, and contexts screens.
- Initialize Telegram WebApp SDK when available.
- Support local browser development without Telegram.
- Keep BCB API calls isolated behind a frontend client module.
- Use a mocked API adapter for Phase 1.
- Document local run instructions and Phase 2 secure auth bridge requirements.

## Out Of Scope

- n8n integration.
- CRM integration.
- Production assistant publishing or writes.
- Backend BCB schema changes.
- New backend service or public port.
- Exposing internal webhook token in frontend code.

## Checks

- Static JavaScript syntax checks where available.
- No backend tests unless backend files change.
