# T-bcb-design-ui-prototype

## Goal

Create an isolated clickable UI prototype for the future Business Context Builder experience.

## Scope

- Add a standalone static prototype separate from the existing Telegram Mini App.
- Include login, bots dashboard, business context builder, interview wizard, and bot settings screens.
- Use mock data and placeholder controls only.
- Use a clean Swiss SaaS mobile-first visual style with white background and blue accents.
- Keep existing assistant platform behavior untouched.

## Out Of Scope

- Existing assistant configuration changes.
- Prompt builder changes.
- Backend API changes.
- Database schema changes.
- Telegram Mini App functionality changes.
- Authentication changes.
- Integration or workflow changes.
- Docker, environment, nginx, or deployment changes.

## Checks

- Static JavaScript syntax check for the prototype.
- `git diff --check`.
