# Phase 1.5 — Git truth normalization

**Status:** in-progress  
**Date:** 2026-05-27

## Goal

Normalize repository truth into a canonical reproducible baseline without changing runtime behavior.

## Scope

1. tracked vs ignored classification
2. `.gitignore` normalization
3. canonical runtime artifact preservation rules
4. runtime garbage/temp artifact cleanup policy
5. secret-commit prevention safeguards
6. migration chain reproducibility integrity checks
7. test reproducibility artifact policy
8. workflow export artifact governance

## Constraints

- Do not change runtime behavior.
- Do not redesign architecture or orchestration.
- Do not add feature work.
- Do not expose secrets.
- Do not perform Docker or workflow logic implementation.

## Deliverables

- normalized `.gitignore`
- explicit classification notes for track/ignore/review/no-go
- pre-commit review matrix for safe commit grouping
