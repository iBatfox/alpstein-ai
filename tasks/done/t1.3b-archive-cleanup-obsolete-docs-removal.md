# Phase 1.3B — archive cleanup and obsolete docs removal

**Status:** ready (docs-only cleanup)  
**Date:** 2026-05-27

---

## Goal

Clean obsolete, superseded, duplicated, and stale documentation safely after Phase 1.3A tier moves.

Primary references:

- `docs/project-status/documentation-topology-status.md`
- `docs/architecture/canonical-runtime-architecture.md`
- current git state after Phase 1.3A

---

## Scope

1. Identify candidates:
   - obsolete plans
   - superseded-by-spec docs
   - stale architecture notes
   - abandoned migration docs
   - duplicate task docs
   - duplicate audits
   - dead references

2. Categorize each candidate:
   - **archive**
   - **delete**
   - **keep historical**
   - **keep deprecated**

3. Apply deletions **only** for:
   - exact duplicates
   - obsolete docs with a canonical replacement
   - stale generated status docs superseded elsewhere

4. Archive instead of delete when:
   - historical engineering decisions matter
   - migration history matters
   - old runtime context may still be useful

5. Update only what is necessary due to path/content changes:
   - `docs/README.md`
   - `docs/architecture/deprecated/README.md`
   - `docs/project-status/{README.md,documentation-topology-status.md,historical/README.md}`

---

## Constraints

- No runtime changes.
- No architecture redesign/rewrite.
- No broad prose rewrite.
- Preserve engineering history where valuable.
- Do not commit until review.

## Verification

- Hash-based duplicate scan of tracked markdown docs.
