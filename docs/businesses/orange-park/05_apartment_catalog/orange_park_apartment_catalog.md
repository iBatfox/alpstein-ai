# Orange Park Apartment Catalog

This source is an extension point for a future manager-approved apartment
catalog integration.

No live prices, current availability, apartment photos, image galleries,
specific unit claims or external catalog API data are approved here.

The dialog may collect apartment type, desired area, purpose and purchase path.
Current options must be confirmed by a manager.

Approved non-live reference range:

- 2-room apartments: `56-64 м²`.

This range is for qualification and comparison only. It does not prove current
availability, price, floor, layout, or a specific unit.
